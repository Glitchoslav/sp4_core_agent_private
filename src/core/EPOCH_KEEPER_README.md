# 🔥 SP4_EPOCH Keeper v1.0

**Modul na zapisovanie všetkých dôležitých zmien v systéme ako epochy.**

Generated by: Full Autonomy v2.0 (Mission `m_20251125_625066`)

---

## 📋 Čo to je?

**Epoch** = významná zmena v systéme, ktorú chceš zachytiť do histórie.

Príklady epoch:
- ✅ Nasadenie nového modulu
- 🐛 Oprava kritického bugu
- 🚀 Deploy do produkcie
- 💡 Dôležitá user decision
- 🔧 Refaktor core systému

---

## 🚀 Použitie

### CLI Príkazy

```bash
# Zaznamať novú epochu
/epoch SP4_EPOCH Keeper deployed

# Zobraziť posledných 20 epoch
/epochs
```

### Programatický prístup

```javascript
import { recordEpoch, displayEpochs, getLatestEpochs } from './src/core/epochKeeper.js';

// Pridanie epochy
await recordEpoch('Opravený kritický bug v memory systéme', {
    bug: 'memory.json corrupted',
    fix: 'Added duplicate bracket detection'
});

// Zobrazenie epoch
await displayEpochs(10);

// Získanie epoch (array)
const latest = await getLatestEpochs(5);
console.log(latest);
```

---

## 📊 API

### `recordEpoch(description, data = {})`

Zaznamá novú epochu.

**Params:**
- `description` (string) - popis zmeny
- `data` (object, optional) - dodatočné metadata

**Returns:** `Promise<Epoch>`

**Example:**
```javascript
await recordEpoch('Full Autonomy v2.0 enabled', {
    version: '2.0.0',
    features: ['autonomous planner', 'execution orchestrator']
});
```

### `getLatestEpochs(count = 10)`

Získa posledných N epoch.

**Returns:** `Promise<Epoch[]>`

### `displayEpochs(count = 10)`

Zobrazí posledných N epoch v konzole.

**Returns:** `Promise<void>`
