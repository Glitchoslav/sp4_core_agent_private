### Issue #2: Manifest Timeout (60s+)
- **Root:** Long system prompt + multi-persona instructions
- **Symptom:** llama3:8b times out on manifest generation
- **Fix:** Mini-system prompt for manifest mode
  ```javascript

  // "Si SP4 hlas. 1–2 odstavce. Offline-first. Slovensky."
  ```

### Issue #3: Glitch-Slovak (Raw but Good)
- **Root:** Enforcer works but has no normalization filter
- **Symptom:** Output has typos: "smysl" → "zmysel", "navrhoené" → "navrhnuté"
- **Fix:** Micro-layer regex filter (NOT another LLM call)
  ```javascript
  .replace(/smysl/gi, "zmysel")
  .replace(/navrhoen(e|ý)/gi, "navrhnut$1")
  ```
