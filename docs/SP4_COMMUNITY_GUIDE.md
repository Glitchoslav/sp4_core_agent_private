**Krok 1: Nainštaluj Ollama**
```bash

curl https://ollama.ai/install.sh | sh

# Alebo stiahni z: https://ollama.com
```

**Krok 2: Stiahni model**
```bash

```

**Krok 3: Clone SP4_CORE_AGENT**
```bash
git clone https://github.com/Glitchoslav/sp4_core_agent_private.git
cd sp4_core_agent
npm install
```

**Krok 4: Spusti**
```bash
npm start
# alebo: node index_v07.js
```
